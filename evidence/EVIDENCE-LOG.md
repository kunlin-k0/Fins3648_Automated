



# Evidence log

Every sourced fact goes here **when found**, not later. If it is not in this log, it does not
go in a deliverable. `course-alignment-check` audits against this file.

## Two-gate rule (CLAUDE.md Rule 13)
Every row starts as **PROPOSED** (found by the AI). It becomes **VERIFIED** only after Kunlin
manually opens the source and confirms it. Autonomous/overnight runs may add PROPOSED rows;
they may **never** mark anything VERIFIED. Unverified claims appear in drafts as
`[UNVERIFIED — Kunlin to confirm]`.

## Type key
- **course** — a FINS3648 concept. Cite as `[W<n>: concept]`. Must appear in `/course/`.
- **external** — a real published source. Full citation required.
- **assumption** — no source exists. Must carry a stated basis and be labelled in the text
  as `[ASSUMPTION: … — basis: …]`.

## State key
- **PROPOSED** — found by the AI, link not yet checked by a human. Provisional.
- **VERIFIED** — Kunlin opened the source and confirmed it says what the claim says.
