# results/drafts/

Every run of the orchestrator lands **one integrated draft** here.

## Naming
`draft_YYYY-MM-DD.md` — first draft of the day. Add `-2`, `-3` for further drafts the same
day: `draft_2026-07-24-2.md`.

## What a draft is
- One self-contained, AI-friendly document covering the **whole** project — all five roles,
  the logic, the claims, the evidence, and a per-person peer map (CLAUDE.md Rules 5, 7, 10).
- A **reasoning/traceability** document — NOT a PPT, NOT the report.
- **Never final.** It exists to be challenged. Copy `TEMPLATE-draft.md` to start one.

## The loop
1. Run → new `draft_…md` (all PROPOSED evidence, nothing approved).
2. Kunlin verifies sources (PROPOSED → VERIFIED).
3. Kunlin + team drop the file into AI, send feedback.
4. Refine → next dated draft; log the silent marker in `/private/`.
5. When stable → deck first, then report, both from the latest draft.
