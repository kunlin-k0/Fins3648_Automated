# /course — knowledge base

Condensed notes for FINS3648 Weeks 1–7, plus the assessment spec and case index.
These are the **only** course source the agent should reason from.

- `00-assessment-spec.md` — authoritative on deadlines, budgets, structure. Read first.
- `week-0*.md` — one file per week: concepts, cases, examinable traps, deck links.
- `cases.md` — what each case is *for*. Never cite a case without checking this.
- `readings.md` — extended materials and what each is good for.

Concept citation format used throughout the deliverables: `[W<n>: <concept>]`, e.g.
`[W2: API-as-gatekeeper]`. The concept must actually appear in that week's file.
